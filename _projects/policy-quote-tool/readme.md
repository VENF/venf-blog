# Cotizador de pólizas

Demo interactivo de un cotizador de primas de pólizas de salud.

**Funcionalidades:**

- Formulario con datos del solicitante (nombre, email, teléfono)
- Gestión de grupo familiar con roles y edades
- Selección de compañía, plan y suma asegurada
- Cálculo automático de primas por rango de edad
- Cobertura opcional de maternidad
- Factura detallada con desglose de primas y opciones de pago
- Animaciones con Framer Motion

**Stack:** Next.js, React, TypeScript, React Hook Form, Zustand, Zod, Tailwind CSS, shadcn/ui, SWR

> Los nombres de compañías y planes son ficticios.
